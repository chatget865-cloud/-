# مسابقة عُمان المجد — الحزمة الموحدة

هذه حزمة كاملة لرفعها إلى مستودع GitHub الحالي ثم نشرها تلقائيًا على Render.

## طريقة التحديث
1. احتفظ بنسخة احتياطية من المستودع ومن نتائج المشاركين (CSV) قبل أي تغيير.
2. فك ضغط الحزمة. ارفع **محتوياتها** إلى جذر مستودع GitHub، مع الحفاظ على مجلد `static`، واستبدل الملفات المطابقة. يفضّل استخدام GitHub Desktop لرفع التحديث كله في عملية Commit واحدة، لأن واجهة GitHub قد لا تدعم استبدال ملفات متطابقة برفع مجلد دفعة واحدة.
3. **لا تحذف قاعدة PostgreSQL في Render** ولا تنشئ خدمة جديدة.
4. انتظر Live في Render. حدّث المتصفح Ctrl+Shift+R.
5. افتح `/admin`، علّم المشاركات التجريبية، وجرّب المشاركة باسم جديد.

## المزايا
- دخول بالاسم وجهة العمل دون رمز، ومحاولة واحدة للاسم والجهة نفسيهما (لا يثبت الهوية بصورة قاطعة).
- بنك 150 سؤالًا، 30 سؤالًا لكل مشارك، 30 ثانية لكل سؤال.
- شهادة احتفالية قابلة للطباعة PDF من المتصفح، مع اعتماد رقية علي الفارسي.
- مؤثرات صوتية أصلية بسيطة تتولد محليًا من المتصفح، مع زر كتم؛ قد لا تعمل قبل أول تفاعل بسبب سياسات المتصفح.
- لوحة إدارة لإغلاق/فتح المسابقة، تمييز الاختبارات التجريبية، وتصدير CSV بتوقيت عُمان.

## تنبيه
الاستضافة وقاعدة البيانات المجانيتان في Render غير مناسبتين لضمان حفظ نتائج مسابقة رسمية طويلة الأمد. راجع التكاليف والنسخ الاحتياطي قبل الإطلاق. لا توزع كلمة مرور الإدارة.
